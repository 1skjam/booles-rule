Worked Examples

Two fully worked examples demonstrating Boole's Rule from setup through final answer.

Boole's Rule — Quick Reference
\[ \int_a^b f(x)\,dx \approx \frac{2h}{45}\bigl[7f(x_0)+32f(x_1)+12f(x_2)+32f(x_3)+7f(x_4)\bigr], \quad h = \frac{b-a}{4} \]
Example 01

Integrating \(f(x) = x^4\) on \([0, 2]\)

Given
\[ f(x) = x^4, \quad a = 0, \quad b = 2 \]

We want to approximate \(\displaystyle\int_0^2 x^4\,dx\).

The exact value is \(\dfrac{x^5}{5}\Big|_0^2 = \dfrac{32}{5} = 6.4\).

Step 1 — Compute \(h\)
\[ h = \frac{b - a}{4} = \frac{2 - 0}{4} = 0.5 \]
Step 2 — Find the Node Points
\[ \begin{array}{ll} x_0 = a = 0 & x_1 = 0 + 0.5 = 0.5 \\[6pt] x_2 = 0 + 1.0 = 1.0 & x_3 = 0 + 1.5 = 1.5 \\[6pt] x_4 = b = 2.0 \end{array} \]
Step 3 — Evaluate \(f(x) = x^4\) at Each Node
\(i\)\(x_i\)\(f(x_i) = x_i^4\)
0\(0.0\)\(0.0^4 = \mathbf{0.0000}\)
1\(0.5\)\(0.5^4 = \mathbf{0.0625}\)
2\(1.0\)\(1.0^4 = \mathbf{1.0000}\)
3\(1.5\)\(1.5^4 = \mathbf{5.0625}\)
4\(2.0\)\(2.0^4 = \mathbf{16.0000}\)
Step 4 — Compute the Weighted Sum
\[ W = 7f(x_0) + 32f(x_1) + 12f(x_2) + 32f(x_3) + 7f(x_4) \] \[ W = 7(0) + 32(0.0625) + 12(1) + 32(5.0625) + 7(16) \] \[ W = 0 + 2 + 12 + 162 + 112 = \mathbf{288} \]
Step 5 — Apply Boole's Rule
\[ \int_0^2 x^4\,dx \approx \frac{2h}{45} \times W = \frac{2(0.5)}{45} \times 288 = \frac{1}{45} \times 288 = \mathbf{6.4} \]
Result
\(\approx 6.4000\)
Exact value: \(6.4\)  |  Error: \(0\)

Boole's Rule is exact for \(f(x) = x^4\) because it is exact for all polynomials of degree ≤ 5.

Example 02

Integrating \(f(x) = \sin(x)\) on \([0, \pi]\)

Given
\[ f(x) = \sin(x), \quad a = 0, \quad b = \pi \]

We want to approximate \(\displaystyle\int_0^{\pi} \sin(x)\,dx\).

The exact value is \(-\cos(x)\Big|_0^{\pi} = -\cos(\pi) + \cos(0) = 1 + 1 = 2\).

Step 1 — Compute \(h\)
\[ h = \frac{\pi - 0}{4} = \frac{\pi}{4} \approx 0.7854 \]
Step 2 — Find the Node Points
\[ \begin{array}{ll} x_0 = 0 & x_1 = \dfrac{\pi}{4} \approx 0.7854 \\[10pt] x_2 = \dfrac{\pi}{2} \approx 1.5708 & x_3 = \dfrac{3\pi}{4} \approx 2.3562 \\[10pt] x_4 = \pi \approx 3.1416 \end{array} \]
Step 3 — Evaluate \(f(x) = \sin(x)\) at Each Node
\(i\)\(x_i\)\(f(x_i) = \sin(x_i)\)
0\(0\)\(\sin(0) = \mathbf{0.0000}\)
1\(\pi/4\)\(\sin(\pi/4) = \mathbf{0.7071}\)
2\(\pi/2\)\(\sin(\pi/2) = \mathbf{1.0000}\)
3\(3\pi/4\)\(\sin(3\pi/4) = \mathbf{0.7071}\)
4\(\pi\)\(\sin(\pi) = \mathbf{0.0000}\)
Step 4 — Compute the Weighted Sum
\[ W = 7(0) + 32(0.7071) + 12(1) + 32(0.7071) + 7(0) \] \[ W = 0 + 22.6274 + 12 + 22.6274 + 0 = \mathbf{57.2548} \]
Step 5 — Apply Boole's Rule
\[ \int_0^{\pi} \sin(x)\,dx \approx \frac{2h}{45} \times W = \frac{2 \cdot \tfrac{\pi}{4}}{45} \times 57.2548 = \frac{\pi}{90} \times 57.2548 \] \[ = 0.034907 \times 57.2548 \approx \mathbf{1.9998} \]
Result
\(\approx 1.9998\)
Exact value: \(2.0000\)  |  Error: \(\approx 0.0002\)

Boole's Rule yields an excellent approximation of \(\sin(x)\) with a relative error of only 0.01% — impressive for just five function evaluations.
